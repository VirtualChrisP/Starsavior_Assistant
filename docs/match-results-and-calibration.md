# 对局结果与本机推荐校准

## 功能范围

Draft 完成后，BP 页面会显示赛后记录区。用户可以录入胜负、结束方式、对局时长和复盘备注。同一个 `draftId` 重复保存时更新原记录，不会生成重复样本。

记录保存在浏览器本机的 `localStorage` 中，键名为 `star-savior-bp-match-history-v1`。页面支持导出完整 JSON，便于备份和后续迁移。每条记录同时保存完整 BP 动作、双方阵容、禁用结果，以及本局涉及角色的装备与技能覆盖快照。

## 推荐校准

推荐引擎会统计候选角色在本机有效历史中的表现：

- `unknown` 结果和 `invalid` 对局不参与统计；
- 只统计与当前 Draft 相同版本、相同服务器的记录；
- 平局按半胜计算；
- 使用 4 场、50% 胜率的先验做贝叶斯平滑，避免少量样本造成过度偏移；
- 校准分为 `(平滑胜率 - 50%) × 20`，最终限制在 `-10` 到 `+10` 分；
- 推荐理由会显示样本数、平滑胜率和实际校准分。

这项校准只修正规则评分，不把本机历史解释为全局胜率。角色技能、阵容功能、操作顺序和数据完整度仍是推荐的主体依据。

## 后续扩展

数据结构已保留补丁、地区、对局模式和装备覆盖快照。积累足够样本后，可以增加阵容组合、对位、先后手和相邻版本衰减的分层统计。
