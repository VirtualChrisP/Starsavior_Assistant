# 阶段 0 验证报告

> 完成时间：2026-09-20

## 结论

阶段 0 的项目基线已经完成，但还没有完成客户端内的规则最终确认。由于仓库此前没有现成代码或数据，本阶段建立了后续实现所需的初始文档和数据契约。

## 当前已经具备的内容

- Ranked Arena、Draft、PvP 计时、数值标准化和轮换 Ban 的公开资料整理。
- 一篇公开 Ranked Match 示例中的有序 Ban/Pick 记录。
- 角色、技能、装备和版本历史等静态资料来源。
- 可版本化的角色数据 Schema。
- 一份角色种子列表，所有未验证字段都保持为空。

## 当前还不具备的内容

- 可直接下载的逐局 BP 比赛数据集。
- 已确认的 Ranked Match 历史 API。
- 亚服目标已经确认，但尚未取得客户端精确构建号和客户端内验证记录。
- 已通过客户端确认的完整 Draft 顺序和队列限制。
- 已通过客户端确认的技能系数和 PvP 公式。

## 阶段结论

可以进入阶段 1，但必须先完成一次手动验证，并建立一个小规模、结构化的知识库。`data/characters.seed.json` 中的角色在目标客户端和版本确认前，不得用于正式推荐或模型训练。

## 进入阶段 1 前需要的输入

1. 一张或一段当前版本的完整 BP 界面截图/录像。
2. 目标服务器地区和 Ranked 队列。
3. 至少 5 局手动记录的完整 Draft，最好包含最终结果。
4. 当前角色列表，最好同时包含角色头像或客户端名称。
