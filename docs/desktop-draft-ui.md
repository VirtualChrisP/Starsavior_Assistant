# 桌面端 Draft 操作界面

## 启动

在项目根目录运行：

```text
npm run dev
```

然后打开：

```text
http://127.0.0.1:4173/
```

这是零依赖的本地 PC 优先界面。当前先使用本地 Node 静态服务承载页面，后续可以直接包装进 Tauri 或 Electron，不需要改写 Draft 状态逻辑。

## 当前功能

- 读取亚服 55 人阵容、知识库和阶段式 Draft 规则；
- 展示首轮同时禁用、`1-2-2-2-2-1` 选人和末轮同时禁用的阶段进度；
- 记录随机首选方，并自动切换当前操作阵营；
- 角色搜索、属性筛选、职业筛选；
- 点击角色立即记录 Ban/Pick，非法角色会被禁用；
- 双方 5 人阵容、禁用记录和末轮被禁用状态展示；
- 撤销、重开和浏览器本地自动保存；
- 已录入完整技能数据的角色显示技能资料标记；
- 角色卡的信息按钮可以打开 Tychara 全身像、基础属性和技能详情；
- `Ctrl+Z` 撤销上一步，`/` 快速聚焦搜索框。

## 数据边界

角色头像和全身像来自 `data/tychara.characters.json` 中的 Tychara 公开页面资源；加载失败时自动使用本地首字母占位，不影响 Draft 操作。当前界面只执行规则校验，不给出胜率或阵容强度结论。
