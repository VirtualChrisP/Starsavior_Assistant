# Star Savior BP 助手

面向 PC 端的《Star Savior》亚服 PvP BP 助手原型。项目当前以规则驱动为核心，在没有完整比赛数据的情况下，基于角色、技能、标签和 BP 状态生成可解释的选人/禁用建议。

## 当前内容

- 亚服 BP 流程状态机：双方随机决定先手，按 `1-2-2-2-2-1` 选人，然后双方同时各禁用对方阵容中的一个角色。
- 角色与技能知识库：包含角色基础信息、技能文本、结构化技能效果、标签和数据来源。
- 桌面端原型页面：展示当前阶段、双方阵容、可用角色、推荐操作和规则事件日志。
- 校验与测试脚本：用于检查知识库、角色名单、网页采集数据和标准化技能数据。

## 环境要求

- Node.js 18 或更高版本
- Windows、macOS 或 Linux

## 启动

```bash
npm run dev
```

启动后打开 <http://127.0.0.1:4173/>。

## 校验与测试

```bash
npm run validate
npm test
```

## 数据说明

角色和技能数据来自项目内的公开资料整理及 Tychara 角色页面快照，数据可能随游戏版本变化。正式使用前应根据亚服最新客户端或公告复核技能文本、数值和角色可用状态。

## 项目结构

```text
data/       角色、技能、来源和知识库数据
docs/       设计、数据模型和阶段计划文档
public/     PC 端原型界面
src/        BP 状态机、规则引擎和建议逻辑
test/       自动化测试
tools/      数据导入、校验和开发服务器脚本
```
